Threat Data Generation & Pre-Processing Pipeline

The dataset factory behind the AI. A modular pipeline that generates, pre-processes, and quality-tests detection datasets — evolved through three major versions as the team's data needs grew from ad-hoc scripts to a dependable supply chain for analyzers and quality testing.

The Problem

Detection quality work runs on data: labeled samples for testing rules, processed feeds for training analyzers, and clean datasets for regression checks. When each need is served by one-off scripts, you get inconsistent formats, silent breakage, and unrepeatable results. The team needed dataset production to work like a pipeline, not a pile of scripts.

The Solution

A modular pipeline organized around three stages, each independently runnable and versioned:

  • Data generation — harvesting and assembling raw detection data from sources including rule-metadata stores (database-backed collection jobs).
  • Pre-processing — normalization, cleaning, and transformation modules that turn raw harvests into analysis-ready datasets.
  • Quality testing — an integrated sample-quality toolkit validating datasets before they're consumed downstream.

Engineering Highlights

  • Three major versions — I refactored the architecture twice as requirements grew, migrating consumers each time while keeping older module generations archived and runnable for reproducibility.
  • Module interchangeability — generation, pre-processing, and testing stages plug together, so new data sources only require a new generation module, not a new pipeline.
  • Backup and versioned workflows — datasets and module versions are kept recoverable; results can be traced back to the exact module generation that produced them.
  • Force multiplier — this pipeline fed labeled data to the SIEM alert-triage analyzer and supported the team's broader quality-testing workflows.

What this project demonstrates: long-horizon ownership — evolving a system through multiple architectures as needs changed, with reproducibility and versioning discipline that most script collections never get.
